# Dua App

A Flutter dua app with:

- Splash screen with app icon
- Dua index page
- Dua detail page after tapping an index item
- Forward, backward, favorite, and share actions
- Top and bottom ad slots on every page except the splash screen

## Run

If platform folders are missing, generate them first:

```sh
flutter create .
```

Then run the app:

```sh
flutter pub get
flutter run
```
